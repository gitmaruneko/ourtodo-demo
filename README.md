# ourtodo Demo

[開啟互動展示](https://gitmaruneko.github.io/ourtodo-demo/)

無須 LINE 登入，可新增與編輯任務、切換狀態與日曆、預覽照片。資料僅保存在自己的瀏覽器 localStorage；不連接正式 API，不使用 Cloudflare Workers 或 D1，不提供多人同步。請勿輸入敏感資料，可隨時重設示範資料。

這個 repository 只保存靜態建置產物。唯一程式碼來源：[gitmaruneko/ourtodo](https://github.com/gitmaruneko/ourtodo/tree/0f8a539e45247c3f60e30debdffe75e8e09bf096)，來源提交：0f8a539e45247c3f60e30debdffe75e8e09bf096。更新請在來源專案執行 npm ci、npm run build:demo，再發布 dist-demo 的內容。
